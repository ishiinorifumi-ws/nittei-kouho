日程候補メーカー

Google カレンダーの空き時間から「以下の日程でご都合いかがでしょうか。」の文面を作ります。

1. ブックマークバーに登録する

登録すると、ブックマークバーには次のように表示されます。

A の場合 日程候補
B の場合 日程候補

A. ドラッグで登録する（かんたん）

下のボタンをブックマークバーへドラッグします。この方法ではアイコンが付きません。

日程候補

このページでクリックしても何も起きません（Google カレンダーの画面で使うものです）。

B. アイコン付きで登録する

ブックマークバーにカレンダーのアイコンを付けたいときは、ファイルを取り込む方法で登録します。

  2. Chrome はアドレスバーに chrome://settings/importData、Edge は edge://settings/profiles/importBrowsingData と入れて開きます。
  3. 取り込み元で「ブックマークの HTML ファイル」（Edge は「お気に入りまたはブックマークの HTML ファイル」）を選び、保存したファイルを指定します。
  4. ブックマークバーに「インポートしたブックマーク」フォルダができます。中の「日程候補」をバーへドラッグで出し、空になったフォルダは右クリック →「削除」で消します。

2. 初回だけ iCal アドレスを設定する

先にアドレスをコピーしてから「日程候補」を開きます。パネルを先に開くと歯車が隠れてしまいます。

  1. Google カレンダーを開き、右上の歯車 →「設定」を押します（設定画面を直接開く）。
  2. 左の「マイカレンダーの設定」で自分の名前を押し、「カレンダーの統合」まで下へ進みます。
  3. 「iCal 形式の非公開アドレス」の右のコピーボタンでアドレスをコピーします。
  4. ここで初めてブックマークの「日程候補」を押します。パネルの「設定」が開いているので、「iCal アドレス」に貼ります。

設定画面のままでもパネルは使えます。貼ったら左上の「←」でカレンダーに戻っても構いません。アドレスはこのブラウザの calendar.google.com 用の保存領域にだけ残ります。外部には送りません。

3. 使い方

  1. Google カレンダーで「日程候補」を押すと、右上にパネルが開きます。
  2. 近い日から 3 枠（1日1枠まで）が最初から選ばれています。
  3. 時刻を押すと選択を切り替えます。日付を押すとその日の空き枠をまとめて選びます。
  4. 「コピーする」で文面をクリップボードに入れ、メールや Slack に貼ります。

朝・昼・夕方など候補に出したくない時間は「除外する時間」に 12:00-13:00, 金16:00-18:00 のように書きます。設定は次回も残ります。もう一度ブックマークを押すか Esc で閉じます。
